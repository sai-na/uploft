Is there a Chrome extension that makes Google Drive uploads more reliable?

Published 29 October 2026 · Updated 29 October 2026 · By Sai Nath

Yes. Uploft is a free Chrome extension (Chrome 116 or later) that adds an uploader which resumes after dropped connections, closed tabs and restarts, plus automatic Retry and keep-awake for uploads started in Drive. It is not on the Chrome Web Store yet, and it cannot lift Google's limits.

This guide comes from the maker of Uploft. Google's scopes and steps link to Google's own pages and were checked on 29 October 2026; what the extension does comes from its source code.

What can a Chrome extension do for Drive uploads, and what can it not do?

An extension can do three things: add its own uploader page that talks to Google's Drive API, watch the drive.google.com tab and help it, and ask Chrome to keep the computer awake. It cannot change how Google's servers accept data, raise Google's limits or make your connection faster.

That split decides what is worth installing. An extension with its own uploader can resume a file from the last piece Drive confirmed. One that only watches Drive's tab can retry, notify and keep the tab loaded, but an upload started in that tab still ends if the tab is closed. Google's own alternative for uploads that do not depend on a tab is Google Drive for desktop, available for Windows and macOS.

What should I check before installing one?

Check three things: the permissions it asks for, the Drive access it requests when you sign in, and whether its source code can be read. Chrome's help says to approve only extensions you trust.

  • Chrome permissions. Uploft asks for storage, notifications, power and identity, plus access to drive.google.com and www.googleapis.com. It needs no access to other websites.
  • Drive access. It asks for the drive.file scope. Google lists it among its non-sensitive scopes and says it lets an app create new Drive files, or modify existing files, that you open with the app or share with it through a file picker. It does not give the extension a view of the rest of your Drive.
  • Source code. The code is public on GitHub, so the permissions above can be compared with what the code does.
  • Privacy. The privacy page says the extension has no analytics, no ads and no third-party trackers.

One consequence of drive.file: the extension can only see files it uploaded itself. Its Skip and Replace choices for files already in Drive therefore apply to files it put there, not to files uploaded some other way.

What does Uploft do?

Uploft is a free Manifest V3 extension for Chrome 116 or later. It has two parts: an uploader page, and a helper that runs on drive.google.com.

The uploader page

Click the toolbar icon, then Upload files to Drive, and sign in with Google. The uploader sends files with Drive's resumable uploads.

  • It uploads 1 to 6 files at a time (4 by default).
  • After a dropped connection, a closed tab or a restart, it continues from what Drive already received. Chrome may ask permission to read a file again.
  • For a file already in Drive, you choose Skip it, Replace it or Keep both.
  • Files go into an "Uploft" folder in My Drive unless you pick another folder.

The helper on drive.google.com

For uploads you start in Drive's own tab, it shows a progress panel and notifications, presses Drive's Retry button after 5, 20 and 60 seconds, keeps the computer from sleeping through inactivity while uploads run, and stops Chrome discarding the tab. Keep-awake and retry are on by default and can be turned off from the toolbar icon.

For the detail of each part, see how resuming a Drive upload works and why Drive uploads fail.

Is it on the Chrome Web Store?

Not yet. As of 29 October 2026 the extension is at version 1.1.0 and has no Chrome Web Store listing, so there is no one-click install. The home page shows what it does and is where a listing will be linked once there is one.

What are the limits?

  • It needs Chrome 116 or later on a computer. It does not run on phones.
  • Google sign-in for the uploader is in Google's "Testing" mode, so only listed test users can sign in until the app is published.
  • One file uploads at about the speed of Drive's own site, because a single file's pieces go in order. The gain is for batches and for uploads that get interrupted.
  • An upload started in Drive's own tab still ends if that tab is closed. Only the extension's uploader resumes after a closed tab.
  • It cannot lift Google's limits, such as a full storage quota or Drive's daily upload limit.
  • It does not watch folders and sync them. For that, Google's Drive for desktop is the right tool.

Uploft is free, and its source code is public. It isn't on the Chrome Web Store yet; the home page shows what it does and what it asks for.
