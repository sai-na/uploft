Does Google Drive overwrite a file with the same name or make a copy?

Published 29 October 2026 · Updated 29 October 2026 · By Sai Nath

Neither is fixed. Google's upload help says that uploading a file with the same name on drive.google.com adds it as a revision of the file already in Drive, so it overwrites nothing and makes no copy. To get two separate files, click Keep both files. Other tools choose for themselves, and Uploft lets you pick.

This guide comes from the maker of Uploft, the Chrome extension mentioned below. Google's behaviour links to Google's own pages and was checked on 29 October 2026; what the extension does comes from its source code.

New version or a "(1)" copy?

On drive.google.com, a same-name upload becomes a new version. Google's help says: "If you upload a file with the same name, Google Drive will upload the file as a revision of the file already in Google Drive." The file keeps its ID, so its link and sharing stay, and the older contents sit in Manage versions. The steps and the retention rules are in how to replace a file without changing the link.

A copy appears only when you ask for one, or when a tool creates a new file instead of updating the old one. That is a difference between tools, not a Drive rule: the Drive API has separate calls to create a file and to update an existing one.

How do I keep both files on drive.google.com?

  1. On your computer, go to drive.google.com and upload the file.
  2. When Drive asks about the same-name file, click Keep both files.

Google lists these as the steps "To keep both files". The wording of the prompt can change, so check it against your screen.

Which should I choose: Skip, Replace or Keep both?

Uploft's uploader has a setting called If already in Drive with three choices. It compares each file with files of the same name in the destination folder:

SettingWhat happensPick it when
Skip it (the default)A file of the same name and size is skipped ("Already in Drive, skipped"). Same name but a different size is uploaded as a second file.You are re-running a folder and want nothing uploaded twice.
Replace itA changed file becomes a new version of the one in Drive ("Replaced"). Same size and modified time is skipped.You updated files and want the same links to open the new contents.
Keep bothAlways uploaded as a second file.You want every upload kept as its own file.

Replace sends the new contents to the same Drive file ID, which is why the link survives. Keep both and Skip never touch an existing file. The sizes and modified times it compares are described in the replace guide; skipping repeat uploads has its own page, skipping duplicates in Google Drive uploads.

Why does it differ by tool?

Because a tool has to decide what a same-name upload means, and Drive itself lets a tool do either. Google's developer guide describes one call to create a file ("use the create method on the files resource") and a separate one to change a file that exists ("To update an existing file, use PATCH"). A tool that always creates gives you a second file; one that updates gives you a new version.

The extension does both on purpose: Replace updates the existing file, Keep both creates a new one. Google's own desktop app, Drive for desktop, is another way to upload; how it treats same-name files is for Google's help, not this page.

What are the limits?

  • Skip and Replace only know about files the extension uploaded itself, because it uses the narrow drive.file permission. A same-name file put there another way is invisible to it, so a second file is added.
  • Old versions follow Drive's retention rules, so they can be deleted after a time unless kept forever.
  • It runs in Chrome 116 or later on a computer, and it is not on the Chrome Web Store yet.

Uploft is free, and its source code is public. It isn't on the Chrome Web Store yet; the home page shows what it does and what it asks for.
