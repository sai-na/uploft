How do I stop Google Drive uploading duplicates?

Published 29 October 2026 · Updated 29 October 2026 · By Sai Nath

In Uploft's uploader, set If already in Drive to Skip it, which is the default. A file with the same name and size as one the extension already put in that Drive folder is left out and marked "Already in Drive, skipped". Drive's own website instead adds a same-name upload as a new version.

This guide comes from the maker of Uploft, the Chrome extension described below. Google's behaviour links to Google's own pages, checked on 29 October 2026; what the extension does comes from its source code.

How to skip files already in Google Drive

  1. Open the uploader from the extension's toolbar popup (Upload files to Drive).
  2. Next to If already in Drive, choose Skip it. It is the default; the other choices are Replace it and Keep both.
  3. Choose the destination folder.
  4. Click Choose files or Choose folder, or drop them in.

Before sending a file, the uploader lists the files in its destination folder. A file that is already there is marked Already in Drive, skipped, and the summary at the end counts it as "already in Drive". Nothing is sent for it.

What counts as already in Drive?

With Skip it, the uploader compares each file with the files of the same name in the destination folder. It checks two things: the name and the size in bytes. It does not read the contents.

In the destination folderWhat Skip it does
Same name, same sizeSkipped
Same name, different sizeUploaded as a second file with the same name
Different nameUploaded
Same name, but in the BinUploaded: files in the bin are not counted

Two worked cases. A 12,400,000-byte report.pdf is already in the folder, and the same 12,400,000-byte file is dropped in again: skipped. If the copy on the computer was edited and is now 12,451,230 bytes, the sizes differ, so Skip it uploads it as a second report.pdf. To update the file in Drive instead, use Replace it, which uploads a new version; see how to replace a file without changing the link.

Google's upload help describes what Drive's own website does: "If you upload a file with the same name, Google Drive will upload the file as a revision of the file already in Google Drive", and you can click Keep both files to keep two.

Will a retry upload the same file twice?

No. Google's Drive API documentation says the file is returned "only after you successfully upload the file data", so an upload that stops halfway has not created a finished file, and the API's resumable uploads are made to be continued, not repeated. The uploader continues the same upload session after a network drop, a closed tab or a restart, and it does not look for same-name files again while a session is open. A retry therefore carries on from where it stopped.

Google's documentation adds that a resumable session expires after one week. If the uploader's session has expired, the file starts again from the first byte. Because the unfinished upload never became a file, that does not leave a half-copy behind.

If a duplicate appears anyway, two likely causes are a file dropped in twice while the setting was Keep both, or a changed file with a different size under Skip it, as in the table above.

How do I continue a half-done folder?

Drop the same folder in again with Skip it on, and choose the same destination. Subfolders that already exist in Drive are reused, not created again. Files that finished are skipped, and only the missing files are uploaded. A file that was cut off mid-way was never finished in Drive, so it is uploaded again from the start if its session is gone, or continued if the uploader still has it. See how to resume a Google Drive upload for what survives a restart.

Why doesn't Skip see files I uploaded another way?

Because the extension uses a narrow Google Drive permission, drive.file, which Google describes as access to "only the specific Google Drive files you use with this app". The uploader can see files it uploaded and folders you chose for it, and nothing else. A file you added through drive.google.com, or another app, is invisible to it, so Skip it uploads a copy next to it.

What are the limits?

  • Skip it only knows about files the extension uploaded itself, in the destination folder it looks at.
  • It matches by name and size, not content. An edited file that keeps the same size is skipped; use Replace it for updated files.
  • It does not find files with a different name, or in another folder.
  • It does not remove duplicates that already exist. Delete those in Drive.
  • It runs in Chrome 116 or later on a computer, and it is not on the Chrome Web Store yet.
