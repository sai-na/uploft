Why is Google Drive stuck on 'Preparing to upload'?

Published 29 October 2026 · Updated 29 October 2026 · By Sai Nath

Drive says Preparing to upload while the browser reads the list of files you chose, before any file is sent. With a folder of thousands of files, that step can take a long time. Wait a few minutes first. If it still shows nothing, cancel, then upload the folder in smaller batches, one subfolder at a time.

This guide comes from the maker of Uploft, the Chrome extension mentioned below. Google's limits and steps link to Google's own pages and were checked on 29 October 2026; what the extension does comes from its source code.

Is it slow or really stuck?

Google does not document the Preparing to upload message or say how long it should last, so any exact time quoted for it is a guess. What can be said is how the step works. Before a file can be sent, the browser has to list the files in the folder and open each one to read its name and size. A few files take no time; thousands take a while, and the screen can look frozen while it counts. The test is the size of the job:

What you choseWhat to expectTry first
A few files or a small folder Preparing should pass in seconds Reload the Drive tab and try again; check Storage in the left-hand menu
A folder with thousands of files A long preparing step is likely, and it may be working Wait a few minutes, then split it into batches
A folder on an external, network or synced drive Reading each file is slower than on the computer's own disk Copy the folder to the computer first, or upload it in batches
Preparing for a long time, then the panel never appears The tab is stalled or out of memory Reload, then upload fewer files at once

The table gives likely causes from how folder uploads work, not from a Google list. If the upload panel has not appeared at all, rule out the browser first; see why a folder won't upload.

Huge folders

A large file count is the usual reason for a long Preparing step, because the work is per file, not per gigabyte. A folder of 20,000 small photos has far more to read than one 20 GB video. Google's pages do not give a file count where folder uploads stop working, so the safe course is to treat a folder with thousands of files as a job to split up.

Some limits do exist. Google says each user can upload and copy 750 GB to Drive within 24 hours, and a folder over that cannot finish in one day however well it is prepared. Google's limits page also says a shared drive can hold at most 500,000 items, counting files, folders, shortcuts and items in the trash. Neither limit is the cause of a stall that happens before the first file moves, but both matter when a folder is very large.

Upload in smaller batches

Splitting the folder keeps each preparing step short and shows progress sooner. Splitting by subfolder keeps the structure, so nothing needs sorting afterwards.

  1. Cancel the stuck upload and reload the Drive tab.
  2. Choose a target size. For example, a folder of 20,000 files split into batches of 2,000 files gives 20,000 ÷ 2,000 = 10 batches.
  3. Upload the first batch: click New, then Folder upload, and pick one subfolder, or drag a group of files into the Drive window.
  4. Keep the tab open until Drive's upload panel says the batch has finished, then start the next.
  5. Upload the batches into the same Drive folder. Note which batches are done, so none is uploaded twice.

Folder upload and drag and drop are the methods on Google's help page, Upload files & folders to Google Drive; the batching is this guide's advice, not Google's. Google Drive for desktop is an app that syncs a folder on the computer to Drive instead of running in a browser tab, which is another way to move a very large folder. Zipping a folder first gives Drive one file to read instead of thousands, but the folder then arrives as one .zip that has to be unpacked, and a failure restarts the whole archive.

Why is it taking forever?

Once the files start, the time is set by upload speed, not by preparing. Time in seconds is the size in megabits divided by the speed in megabits per second. Worked example: 100 GB is 100 × 8,000 = 800,000 megabits; on a 20 Mbps upload line, 800,000 ÷ 20 = 40,000 seconds, which is 11 hours 7 minutes. Home upload speeds are often far lower than download speeds, so check the upload figure, not the download one. The page how long an upload takes has the same sum for any size and speed.

What the extension does and what it can't

Uploft is a free Chrome extension (Chrome 116 or later, on a computer) with an uploader page of its own. It suits a big folder in a few ways, and has one limit to know.

  • One queue. Choose Choose folder (or drop the folder) and every file in it becomes its own row in the list, with its folder path. At a time runs 1 to 6 at once, 4 by default; the rest show Waiting.
  • Batches without losing the rest. Choose one subfolder after another and every file joins the same queue. Pause all and Resume all hold the queue without losing what is sent.
  • No big file blocks the others. A file that cannot be sent is marked failed after 20 failed tries in a row with no progress, and the rest carry on. Each failed file has a Retry button.
  • Survives a restart. If Chrome closes, choose the files again or press Resume and each file continues from what Drive already holds.

The limit: the uploader also has to list the folder before it can queue it. It opens the files one at a time, and the rows appear when that finishes, so a folder of many thousands of files can take a while to show up in the extension too. It does not make that step faster; splitting a very large folder into subfolders keeps it short. It also cannot fix a full Google storage or the 750 GB daily limit. Uploft for Drive is not on the Chrome Web Store yet.

Uploft is free, and its source code is public. It isn't on the Chrome Web Store yet; the home page shows what it does and what it asks for.
