Does Google Drive limit upload speed?

Published 29 October 2026 · Updated 29 October 2026 · By Sai Nath

Google publishes no upload speed cap for Google Drive. Its pages set a daily upload amount for Google Workspace users and a maximum file size, which are quantities, not speeds. Drive for desktop has a rate limit, but only one you set yourself. In practice your own upload speed is usually the ceiling.

This guide comes from the maker of Uploft, the Chrome extension mentioned below. Google's behaviour links to Google's own pages and was checked on 29 October 2026; what the extension does comes from its source code.

Is there a published cap?

No. The pages Google keeps for Drive limits give amounts and request rates, and none gives a speed in Mbps or MB per second. Google's Drive API limits page lists two upload limits: Workspace users can upload 750 GB per day between My Drive and all shared drives (copies count too), and the largest file is 5 TB. Its other limits are API quotas counted in units per minute, such as 325,000 quota units per minute per user per project. Those count requests, not bytes per second.

The absence of a published figure is not proof that no throttling ever happens. It means only that Google has not documented one, so this guide does not state one.

Per-connection ceiling or quota: which is it?

A speed ceiling limits how fast bytes move. A quota limits how many you may send in total. Drive documents quotas only. The two behave differently:

  • The 750 GB daily limit does not slow a transfer. It lets uploads run at full speed until the amount is reached, then refuses more until 24 hours have passed. See the daily upload limit.
  • The 5 TB file limit refuses a single file above that size. See the file size limit.
  • Your connection is the ceiling you can measure. Work out the time it should take: at 20 Mbps, 20 ÷ 8 = 2.5 MB per second, so 10 GB (10,000 MB) takes 10,000 ÷ 2.5 = 4,000 seconds, about 1 hour 7 minutes. If the real upload is close to that, the line is the limit. The full check is in why uploads feel slow.

Why can several files use more of the line?

Because one file is sent as a single stream of pieces, in order. Google's upload guide describes a resumable upload as a series of chunks, in multiples of 256 KB, and advises keeping each chunk as large as possible. If one stream does not fill your connection, sending a second file alongside it can use the spare capacity. If one stream already fills the connection, extra files only share it and the total stays the same.

A worked case: a 100 Mbps line has 12.5 MB per second to use (100 ÷ 8). If a single file reaches 5 MB per second, 7.5 MB per second is idle, and two more files could in theory take it. If a single file already reaches 12.5 MB per second, nothing is left to gain. Google does not document whether a single stream is ever held below the line speed, so treat the first case as something to test on your own connection.

Bandwidth settings in Drive for desktop

Drive for desktop lets you set a maximum yourself. Google's Customize Drive for desktop settings page says to open the Drive for desktop menu, then Settings, then Preferences, then Advanced Settings, and enter a value next to Download rate or Upload rate. Values range from 1 to 100,000,000, in kilobytes per second.

The limit exists to protect your connection for other things, not to speed anything up. For scale, 2,500 KB per second is the 2.5 MB per second of the 20 Mbps example above, and the top of the range, 100,000,000 KB per second, is 100,000 MB per second, far above any home line. A slow Drive for desktop upload is worth checking against that setting first. Google's page does not state default values.

What does Uploft do?

Uploft is a free Chrome extension (Chrome 116 or later) with its own uploader page. It does not add a limit and cannot raise your line speed or bypass Google's quotas. What it controls is how well one connection is used.

  • Several files at once. Under At a time you choose 1 to 6 files; the default is 3.
  • Piece size that adapts. Each file is sent in pieces that start at 8 MiB. A piece that finishes in under 4 seconds makes the next one twice as large, up to 64 MiB; a piece that takes over 20 seconds halves it, down to 1 MiB.
  • Speed on screen. The uploader shows the current speed and time left, so the figure can be compared with the sum above.

What can't it do?

  • Go faster than your upload speed. One file goes up at about the speed of Drive's own site, because the pieces of a single file are sent in order.
  • Lift the 750 GB daily limit or the 5 TB file limit.
  • Run outside Chrome on a computer, and it isn't on the Chrome Web Store yet.

Uploft is free, and its source code is public. It isn't on the Chrome Web Store yet; the home page shows what it does and what it asks for.
