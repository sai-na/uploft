How do I upload a whole folder to Google Drive?

Published 29 October 2026 · Updated 29 October 2026 · By Sai Nath

On a computer, go to drive.google.com, click New ▸ Folder upload and choose the folder, or drag the folder into the Drive window. Drive uploads everything inside it. Google Drive for desktop does the same in the background: drag the folder into its "Google Drive" folder on your computer.

This guide comes from the maker of Uploft, the Chrome extension mentioned below. Google's steps link to Google's own pages and were checked on 29 October 2026; what the extension does comes from its source code.

How to upload a folder to Google Drive

  1. On your computer, go to drive.google.com.
  2. At the top left, click New, then Folder upload.
  3. Choose the folder you want to upload.

These are the steps on Google's help page, Upload files & folders to Google Drive. The page doesn't list a size or file-count limit for folders. Uploaded files count against your Drive storage, even in a folder someone else owns.

Drag and drop or Choose folder: which one?

Either. Both put the whole folder in Drive. To drag and drop, open or create the destination folder in Drive first, then drag the folder from your computer into the Drive window. Google's third route is Drive for desktop: drag the folder into the "Google Drive" folder it adds to your computer, and it uploads without a browser tab.

Uploft offers the same two ways on its own uploader page: a drop area labelled Drag files or folders here and a Choose folder button next to Choose files.

Are subfolders kept?

Yes, with both of Drive's own ways and with the extension. A folder uploaded to Drive arrives as a folder, with the folders inside it. Google's help page doesn't spell out how nested folders are handled, so the page above is the place to check if it matters for your files.

In Uploft, each file carries its path inside the folder, such as Photos/2024/a.jpg. Before a file uploads, the uploader looks for each folder in that path in the destination and creates the ones that are missing, so the same folders appear in Drive. Files going up in parallel share one lookup, so two files in the same subfolder don't create it twice. Uploading the same folder again reuses the Drive folders it already made.

Three file names are left out of a folder upload: .DS_Store, Thumbs.db and desktop.ini, the hidden files macOS and Windows add.

Where does the folder land in Drive?

On Drive's own site, with drag and drop it goes into the destination folder you opened first (Google's steps). Drive for desktop puts it wherever in the "Google Drive" folder you dropped it.

The extension's destination is shown under Upload to. By default it is a folder called Uploft in My Drive, which it creates on first use. Click the folder name to choose another Drive folder with Google's folder picker. If you click the toolbar icon while a Drive folder is open, the uploader offers that folder with Use that folder. The folder you chose is created inside the destination, not in place of it.

Can you upload several folders at once?

Yes. Drop or choose one folder after another and every file joins one queue. In the extension, the At a time setting runs 1 to 6 files at once, 3 by default, so files from different folders upload side by side. Each file keeps its own folder path.

For many folders, the choice that matters is time: uploads go at your connection's upload speed. 20 GB of folders on a 20 Mbps upload is 20 × 8,000 = 160,000 megabits, and 160,000 ÷ 20 = 8,000 seconds, which is 2 hours 13 minutes.

What if a folder upload stops half-way?

Drive's own site uploads from the open tab, so it is safest to keep that tab open until the upload panel finishes. Google's resumable-upload guide for developers says an upload session expires after a week. The extension keeps the queue and the folder paths. After a closed tab or a restart, the uploader shows an interrupted banner with Resume, and Chrome may ask permission to read the folder again. With the default Skip it, files already in Drive are not sent again, and the rest continue from the last byte Drive confirmed. How resuming works.

If you choose the same folder again, files that match an interrupted upload (same path, size and modified time) carry on instead of starting over.

Limits to know

  • Empty folders: the extension creates a Drive folder when a file needs it, so a folder with no files in it is not recreated.
  • The uploader runs in a Chrome tab. Closing it pauses the queue until you press Resume or choose the folder again.
  • "Skip it" and "Replace it" under If already in Drive only know files the extension uploaded or folders you chose for it, because it uses Google's narrowest Drive permission (drive.file).
  • Your Drive storage still applies; Google lists the limits in its help pages.
  • It runs in Chrome 116 or later on a computer, it isn't on the Chrome Web Store yet, and the Google sign-in is in testing, so only listed test users can sign in for now.

Uploft is free, and its source code is public. It isn't on the Chrome Web Store yet; the home page shows what it does and what it asks for.
