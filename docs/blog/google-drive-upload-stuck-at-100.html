Why is my Google Drive upload stuck at 100%?

Published 29 October 2026 · Updated 29 October 2026 · By Sai Nath

An upload stuck at 100% usually means every byte has been sent but Google Drive has not yet confirmed the file. Wait a few minutes, then open the destination folder in a new tab. If the file is there, the upload worked. If it is not and nothing moves, click Retry in Drive's upload panel.

This guide comes from the maker of Uploft, the Chrome extension mentioned below. Google's behaviour links to Google's own pages, checked on 29 October 2026; what the extension does comes from its source code. Google does not document the "stuck at 100%" state itself, so the explanation of it here is how Drive's upload protocol works, not a Google statement about this symptom.

What does 100% mean?

It means your computer has sent the last byte, not that Drive has finished. Google's Drive API documentation describes the end of an upload as a final response: when the upload finishes, the client "receives a 200 OK or 201 Created response" with the file's details. Until that reply arrives, a progress bar that counts bytes sent can sit at 100%.

So "stuck at 100%" is a wait for Drive's answer. Either the answer is slow, or it was lost on the way back, for example when the connection dropped just after the last piece went out. The file may already be saved either way, which is why the next step is to look, not to start again.

How do I check the file really arrived?

Open the destination folder in a second Drive tab and look for the file. Leave the stuck upload alone while you do.

  1. Open drive.google.com in a new tab and go to the folder you uploaded to. For files from Uploft's own uploader with no folder chosen, that is the Uploft folder in My Drive.
  2. Reload the folder if the file is missing, then search for the file name.
  3. Compare the size with the file on your computer. A smaller file means the upload did not finish.
  4. Open it. A photo or PDF that previews is saved; a video may need longer (see below).

If the file is there at the right size, the upload worked and the stuck bar is only a display problem. Close the stuck upload and carry on. If it is missing or short, the upload did not finish: retry it.

Will retrying make a duplicate?

It can. A retry that starts a new upload is a new file, and the Google pages checked do not say what Drive does with a second file of the same name, so look in the folder first, as above, and delete the extra copy if two appear. A retry that continues the same upload session adds nothing, because the session targets one file.

Uploft works the second way. Its uploader sends each file as one Drive resumable upload and keeps that session's address. When a connection problem hits, it asks Drive how much of the session arrived and continues from there, so a retry at 100% does not start a second file. If you choose the same file again later, the uploader asks what to do about a file already in Drive: Skip it, Replace it or Keep both. It only sees files it uploaded itself.

When Drive is still processing

Some files, videos above all, may be processed by Google after the upload, so a preview might not play at once. No Google help page found gives how long this takes or ties it to the upload bar, so treat any time quoted elsewhere as unconfirmed. What can be said: a file that shows in the folder at its full size has been uploaded, whether or not it plays yet.

Also rule out the account limits, which fail an upload outright rather than leaving it at 100%: Google says that once storage is full "you won't be able to upload or create files in Drive", and a Google Workspace user can upload and copy 750 GB to Drive in 24 hours. Both are covered in Why is my Google Drive upload failing or stuck?

What does Uploft do at 100%?

Uploft is a free Chrome extension (Chrome 116 or later). In its own uploader, a file counts as Uploaded only when Drive returns the finished file, and not when the last byte leaves.

  • It waits for Drive's answer. Once a piece is fully sent, Drive gets 5 minutes to reply. A row can read, for example, "6.3 GB of 6.3 GB" for a while before it changes to "Uploaded".
  • It asks, not guesses. If no answer comes, the piece is treated as a stalled connection and retried. The retry begins by asking Drive how much of the file it has.
  • It keeps going after a restart. Closing the uploader tab or restarting Chrome does not discard the session; see how resuming a Drive upload works.
  • On drive.google.com, it shows its own progress panel and clicks Drive's Retry button after 5, 20 and 60 seconds when an upload fails. It does not change what Drive does after Retry.

What can't it fix?

  • A slow reply from Google. The extension waits and re-asks; it cannot make Drive confirm sooner.
  • An upload in Drive's own tab still ends if you close that tab. Only the extension's uploader picks up after a closed tab.
  • Video processing after the upload, and full storage or the 750 GB daily limit. Those are Google's.
  • It runs in Chrome on a computer, not on phones, and it isn't on the Chrome Web Store yet.

Uploft is free, and its source code is public. It isn't on the Chrome Web Store yet; the home page shows what it does and what it asks for.
