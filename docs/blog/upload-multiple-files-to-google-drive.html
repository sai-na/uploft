How do I upload multiple files to Google Drive at once?

Published 29 October 2026 · Updated 29 October 2026 · By Sai Nath

Select the files on your computer and drag them into the Drive window, or use New ▸ File upload on drive.google.com. Uploft adds a queue: it runs 1 to 6 files at a time (4 by default), keeps the rest waiting and retries a file that hits a network error on its own.

This guide comes from the maker of Uploft, the Chrome extension mentioned below. Google's steps link to Google's own pages and were checked on 29 October 2026; what the extension does comes from its source code.

How to upload multiple files to Google Drive

  1. On your computer, open the folder with your files and select them all (Ctrl+A on Windows, Cmd+A on a Mac, or click and drag a box around them).
  2. On drive.google.com, open the Drive folder you want them in.
  3. Drag the selected files into the Drive window. Or click New, then File upload, and choose the files in the window that opens.
  4. Keep the tab open until Drive's upload panel says it has finished.

Google's help page, Upload files & folders to Google Drive, gives the New menu and drag-and-drop routes, and says to open or create the destination folder first. It doesn't say how many files you can send in one go, and doesn't list a limit on the number of files. Uploaded files count against your Drive storage.

To upload in the background without a browser tab, Google's own option is Drive for desktop: it lets you work with your Drive files in a "Google Drive" folder on your computer, and changes sync automatically.

How many files can you upload at once?

In Uploft, the At a time setting sets how many files upload side by side: 1 to 6, and 3 by default. Files beyond that limit wait as queued, and the next one starts when a running file finishes.

Setting it higher doesn't raise your connection's speed. If one file already uses your whole upload speed, six at once share the same total. What speeds uploads up.

Does it upload only one file at a time?

No, unless you choose 1 file. With the default of 3, three files are in flight together. A single large file is still sent in pieces, one after another, so it goes at about the speed of Drive's own site; extra parallel slots help only when there are several files to send.

To add files, click Choose files (the file dialog allows selecting several) or drag them onto Drag files or folders here. Pick more at any time and they join the same queue.

What about thousands of small files?

Queue them the same way; each file is one job. Small files finish quickly, so the time goes on the per-file start-up rather than on the bytes. Choosing a higher At a time value keeps several in progress at once. For a whole directory use Choose folder, which keeps the subfolders: how folder uploads work.

What happens when one file fails?

Each file is retried by itself. After a network error the uploader waits about 1 second, then 2, then 4, up to about 60 seconds, and tries again from the last byte Drive confirmed. Time offline doesn't count. A file is marked failed after 20 failures in a row without progress, or at once for an error that a retry can't fix; the other files keep going. A failed file has a Retry button in the list.

If the tab is closed or Chrome restarts, the uploader keeps the queue and shows Resume. How resuming works.

Limits to know

  • The uploader runs in a Chrome tab; closing it pauses the queue until you press Resume or choose the files again.
  • More files at once share the same connection; the total speed depends on your upload bandwidth.
  • "Skip it" and "Replace it" under If already in Drive only know files the extension uploaded, because it uses Google's narrowest Drive permission (drive.file).
  • Your Drive storage still applies; Google lists the limits in its help pages.
  • It runs in Chrome 116 or later on a computer, it isn't on the Chrome Web Store yet, and the Google sign-in is in testing, so only listed test users can sign in for now.

Uploft is free, and its source code is public. It isn't on the Chrome Web Store yet; the home page shows what it does and what it asks for.
