Why does my Google Drive upload keep stopping?

Published 29 October 2026 · Updated 29 October 2026 · By Sai Nath

A Google Drive upload keeps stopping when the page sending it loses something it needs: the computer goes to sleep, Chrome unloads the tab, or the connection drops. Plug in, stop sleep, keep drive.google.com active in Chrome, use a steady network and click Retry. Repeated stops at the same point mean a limit.

This guide comes from the maker of Uploft, the Chrome extension mentioned below. Google's limits and steps link to Google's own pages and were checked on 29 October 2026; what the extension does comes from its source code.

Sleep, tab discarded, Wi-Fi, VPN, antivirus

An upload from drive.google.com runs inside the open tab, so anything that interrupts the tab, the computer or the network interrupts the upload. Work through these in order, and test after each change with the same file.

  1. Sleep. Plug the computer in and set its sleep setting so it stays awake while uploading. Chrome's own extension documentation says a keep-awake request prevents sleep "in response to user inactivity", so it does not stop a lid closing or a manual Sleep.
  2. A discarded tab. Open Settings ▸ Performance, click Add next to "Always keep these sites active" and add drive.google.com. Google says Memory Saver "deactivates tabs that you aren't currently using", and its list of tabs it leaves active does not mention uploads.
  3. Wi-Fi. A weak signal or a router that drops the connection stops an upload every time it fails. Use a cable, or sit closer to the router, for large files.
  4. A VPN. A VPN that reconnects or switches servers can cut a connection in the middle of an upload. Turn it off for the upload, or keep it on a stable server.
  5. Antivirus or a firewall. Security software that scans or filters web traffic can interrupt long connections. Pause it briefly, or check its log for blocked connections to Google, to see whether it is involved.
  6. Other tabs and uploads. Several large uploads at once share one connection and make each other slower, which looks like a freeze.

Google does not publish a list of why Drive's website stops an upload, so the order above comes from how a browser upload works, not from a Google table. If the same file stops at the same percentage every time, that points away from the connection: check Storage in Drive's left-hand menu. Google says that when an account reaches its storage limit, "you won't be able to upload or create files in Drive". Google also documents a 750 GB limit on what one Google Workspace user can upload and copy to Drive in 24 hours.

Keeps pausing or freezing

An upload that pauses or freezes, then carries on, is usually waiting for the network or for other files in the queue. One that freezes and never carries on has lost its tab or its connection. Look at the other files in the panel: if some move, the frozen one is queued. If nothing moves, check the network by opening another page, then click Retry on the file.

Google does not say that Drive's website can continue an upload after its tab is closed or reloaded, so assume a reload means starting that file again. That is why a freeze that ends in a reload can cost so much on large files. For a long file, the odds of a stop rise with the time it takes: at 20 Mbps, a 50 GB file takes about 5 hours 33 minutes (50 × 8,000 megabits ÷ 20 Mbps = 20,000 seconds), and all of that time the computer, the tab and the network must stay as they are.

For an upload that does not depend on an open tab, Google makes Google Drive for desktop for Windows and macOS. Google says you can pause or resume its sync at any time.

What are the automatic Retry steps (5 s, 20 s, 60 s)?

With Uploft installed, a failed upload on drive.google.com is retried automatically three times: after 5 seconds, then 20 seconds, then 60 seconds. Each time, the extension clicks Drive's own Retry button on the file. If the computer is offline, it waits for the network to return, then waits 3 more seconds before it retries.

How many failures before it gives up?

On the Drive tab, the extension gives up on a file after the third automatic Retry fails, and, unless upload-failure notifications are turned off, shows a notification so the file is not left unnoticed. In the extension's own uploader the rule is different: it retries a piece again and again, waiting 1 second, then 2, doubling up to 60 seconds, and marks the file failed after 20 failures in a row with no progress, about 15 minutes. Time spent offline does not count towards the 20, and a piece that moves no bytes for 60 seconds is restarted.

A file that fails again after the last retry needs a cause fixed, not another click: storage, the daily limit, the file itself or a connection that does not stay up.

What the extension fixes and what it can't

Uploft is a free Chrome extension (Chrome 116 or later, on a computer). It targets the stops above.

  • Keep-awake. While uploads run it asks Chrome to keep the computer awake from inactivity. It can be turned off in the toolbar popup.
  • No tab discarding. It marks the uploading tab so Chrome does not discard it automatically.
  • Auto-retry as described above, and a progress panel and notifications on the Drive tab.

It cannot fix a full Google storage or the daily limit, a VPN or antivirus that cuts the connection, or a closed lid or manual Sleep. It cannot change what Drive does after Retry. It is not on the Chrome Web Store yet.

Uploft is free, and its source code is public. It isn't on the Chrome Web Store yet; the home page shows what it does and what it asks for.
