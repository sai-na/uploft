Why can't I see my Google Drive upload progress?

Published 29 October 2026 · Updated 29 October 2026 · By Sai Nath

Google Drive's upload box belongs to the page that started the upload, so it can vanish when that tab is closed, reloaded or dismissed. A missing box does not prove the file arrived. Open the destination folder to check, and use a tracker that lists every file's progress.

This guide comes from the maker of Uploft, the Chrome extension mentioned below. Google's behaviour links to Google's own pages, checked on 29 October 2026; what the extension does comes from its source code.

Where does Drive show upload progress?

On the web, Drive shows it in the tab where the upload was started. Google's help pages for uploading on a computer do not describe that upload box, so this guide does not quote its exact wording or rules. The behaviour below is what to expect from an upload that runs inside a web page.

  1. Look at the tab you started from. Switch back to the drive.google.com tab. Progress belongs to that tab, not to Chrome as a whole.
  2. Check for a second window or a second account. A different Chrome window or profile has its own Drive tab and its own upload box.
  3. Look at the folder. Open the destination folder and refresh the page. A file that is still uploading, or has finished, appears there. A file that is missing may never have started.
  4. Use Drive for desktop for background syncing. Google's Drive for desktop shows recent and current sync activity in a "Sync status" tile on its homepage, and shows time-sensitive sync errors in its notifications. See Google's Use Google Drive for desktop page. That is a different method from uploading in a browser tab.

Why does the progress panel disappear?

A progress panel that vanishes usually means the page it belonged to is gone or changed, not that the upload finished. Common causes:

  • The tab was reloaded or closed. A browser upload runs inside the page, so reloading or closing the page ends it, and the box goes with it. Upload the file again. Only the uploader of Uploft picks up after a closed tab; see how resuming a Drive upload works.
  • The tab is in the background. Chrome can freeze or discard background tabs to save memory, and a discarded tab loses its box when it reloads. The extension below stops Chrome from discarding the tab while an upload runs.
  • The computer slept. If the computer goes to sleep, the connection drops and the box may stop moving. See why uploads stop when the computer sleeps.
  • The box was closed by hand. Closing or dismissing the box hides progress; it is not a way to see more. Whether that also cancels the files is not documented by Google, so check the folder before assuming either way.
  • The upload failed. A failed file may show an error only briefly. Check the folder, then retry.

If the box is open but the bar has not moved for minutes, that is a stuck upload rather than a missing one. See why a Drive upload gets stuck.

How do I see progress for each file?

Use a page that lists every file with its own bar, bytes sent and status. Uploft offers two, both free in the same extension.

  • The uploader page. Choose the toolbar icon, then Upload files to Drive, then sign in with Google. Each file shows its status or the bytes sent out of its size, such as "Starting", "Waiting", "Paused", or "Waiting for the network". A summary at the top reads like "0 of 4 files uploaded" with the total bytes, speed and time left.
  • The tracker on drive.google.com. For uploads started in Drive's own tab, the extension adds a floating Uploads panel. Each file gets a card with its name, a progress bar, the percentage, bytes sent out of the total, speed, time left and status. The panel can be dragged and minimised, and it stays where you put it.

How do I know an upload finished?

The reliable check is the file itself: it is in the destination folder and opens. Progress boxes disappear on their own, so a missing box does not tell you either way.

  • In the folder: refresh the destination folder in Drive and look for the file. Size and modified date help for large files.
  • In the uploader page: a file reads "Uploaded" with its size, and the summary reads "All uploads finished". If anything failed, the summary says how many uploads failed.
  • In the tracker panel: a finished card stays for about five seconds and is then removed; a failed card stays for about ten seconds. When the last card goes, the panel hides.
  • By notification: Chrome desktop notifications are on by default for each completed upload, each failed upload and for the end of a batch. Cancelled uploads are off by default. Each can be switched off in the toolbar popup under Notifications.

How does Uploft help?

Uploft is a free Chrome extension (Chrome 116 or later) with public source code. Besides the two progress views above, it presses Drive's own Retry button after 5, 20 and 60 seconds when an upload in Drive's tab fails, waits for the network if the computer is offline, keeps the computer awake from inactivity, and stops Chrome from discarding the tab while uploads run. Both settings are in the popup under Reliability.

The uploader page is the stronger choice when progress matters: it keeps its own queue, so progress survives a closed tab or restart, and the page tells you when a file needs to be chosen again. It sends 1 to 6 files at a time (4 by default).

What can't it fix?

  • An upload started in Drive's own tab still ends if that tab is closed. The tracker panel shows its progress but cannot continue it.
  • The tracker panel reads Drive's own upload box. If Drive changes that box, the panel may stop showing; the uploader page does not depend on it.
  • Full storage, the daily limit and a dead connection are not progress problems. See stuck at 0%.
  • It runs in Chrome on a computer, not on phones, and it is not on the Chrome Web Store yet.

Uploft is free, and its source code is public. It is not on the Chrome Web Store yet; the home page shows what it does and what it asks for.
