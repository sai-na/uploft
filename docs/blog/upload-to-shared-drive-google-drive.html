How do I upload files and folders to a shared drive or shared folder?

Published 29 October 2026 · Updated 29 October 2026 · By Sai Nath

Open the shared drive or shared folder in Google Drive, then drag files in or use New ▸ File upload or Folder upload. You need Contributor or higher on a shared drive, or Editor on a shared folder. In Uploft, choose the destination in its folder picker, which has a Shared drives tab.

This guide comes from the maker of Uploft, the Chrome extension mentioned below. Google's roles and limits link to Google's own pages and were checked on 29 October 2026; what the extension does comes from its source code.

What is the difference between a shared drive and a shared folder?

A shared drive is a space owned by a team. A shared folder is a folder in someone's My Drive that they have shared. Google says "Unlike files in My Drive, files in a shared drive belong to the team instead of an individual", and "Even if members leave, the files stay exactly where they are".

The difference matters to uploaders too. Drive's API treats shared drives as a separate case: Google's developer guide says apps must send supportsAllDrives=true when creating files so that Drive knows the app can handle shared drive items.

Which role do I need to upload?

On a shared drive, Contributor, Content manager or Manager can add files in the web interface; Drive for desktop needs Content manager or Manager. On a shared folder, Editor.

WhereRoleCan add files?
Shared driveManager, Content managerYes
Shared driveContributorYes in the web interface; Google says only read access in Drive for desktop
Shared driveCommenter, ViewerNo
Shared folderEditorYes (Editors can add new files)
Shared folderCommenter, ViewerNo

If the upload option is missing or greyed out, the role is the usual reason. Ask a manager of the drive, or the folder's owner, to change it.

How do I upload a folder to a shared drive?

  1. Open drive.google.com and choose Shared drives in the left menu.
  2. Open the shared drive, and the subfolder if you want one.
  3. Choose New ▸ Folder upload, pick the folder, and keep the tab open until it finishes. Single files use File upload, or drag them into the window.

With Uploft, the steps are different because the uploader is its own page:

  1. Open the uploader from the extension's toolbar icon ▸ Upload files to Drive.
  2. Press the Upload to button and, in Google's folder picker, open the Shared drives tab (a Shared with me tab is there for shared folders). Choose the folder or the drive's top level.
  3. Choose Choose folder, or drag a folder into the window. Folders keep their structure in Drive.
  4. Set At a time (1 to 6 files) and If already in Drive (Skip it, Replace it or Keep both) if the defaults of 3 and Skip don't fit.

Where does Uploft send files?

To the folder you pick. Until you pick one, files go to a folder called "Uploft" in My Drive. If you open the uploader while a Drive folder is open in the current tab, a banner asks "Upload into the folder you had open in Drive?" and a Use that folder button opens the picker at that folder. The extension asks Google for the narrowest Drive permission, drive.file, so it only reaches files it uploaded and folders you choose in the picker; this is why the folder has to be picked rather than typed in.

What are the limits?

  • Your role decides everything. The extension cannot give itself more access than your account has.
  • Skip, Replace and Keep both only see files the extension uploaded itself.
  • The uploader must stay open while files send; it resumes after a closed tab or restart, as the resume guide explains.
  • For a folder kept in sync all the time, Google Drive for desktop is Google's own app.
  • It needs Chrome 116 or later on a computer and a Google account. It isn't on the Chrome Web Store yet, and Google's sign-in screen is in testing, so only listed test users can sign in for now.

Uploft is free, and its source code is public. It isn't on the Chrome Web Store yet; the home page shows what it does and what it asks for.
