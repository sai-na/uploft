Why does my Google Drive upload say 'Waiting' and never start?

Published 29 October 2026 · Updated 29 October 2026 · By Sai Nath

An upload that says Waiting has not started sending yet. Most often it is queued behind other files, because uploaders send only a few at a time. If nothing in the list is moving, the cause is the connection, a paused upload or a sign-in that needs renewing. Check whether any file is moving, then the network.

This guide comes from the maker of Uploft, the Chrome extension mentioned below. Google's limits and steps link to Google's own pages and were checked on 29 October 2026; what the extension does comes from its source code.

Is it a queue or a hang?

Look at the other files first. If at least one file in the list is moving, the waiting ones are in line and will start when a place frees up. If nothing is moving, nothing is in line: the upload is stalled, and the next sections list why. Google does not publish what each label on drive.google.com's upload panel means, so the table gives likely causes from how uploads work, not from a Google list.

What you seeLikely causeTry first
Some files moving, others waiting A queue: only some files upload at a time Wait; nothing is wrong
Nothing moving, no file shows progress No connection, a blocked network or a closed or unloaded tab Open another site, then reload the Drive tab
Waiting for hours with the tab left open The computer slept, Chrome unloaded the tab, or the session expired Keep the computer awake; add the file again
Waiting for the network The connection dropped See Paused, waiting for network
Stuck at 0% after it starts Storage full or the upload never began See Stuck at 0%

Waiting to upload for hours

A file that waits for hours is not in a normal queue. A queue moves as files finish, so a long wait means the files ahead are stalled, or the page sending them has stopped. Work through these in order.

  1. Check the connection. Open any other page to confirm the internet works, and switch from a weak Wi-Fi signal to a cable if you can.
  2. Check Storage in Drive's left-hand menu. Google says that when an account reaches its storage limit, "you won't be able to upload or create files in Drive", and no retry fixes that.
  3. Keep the drive.google.com tab open. Closing it, quitting Chrome or restarting the computer is likely to end an upload started there.
  4. Stop Chrome unloading the tab. Open Settings ▸ Performance, click Add next to "Always keep these sites active" and add drive.google.com. Google says Memory Saver "deactivates tabs that you aren't currently using", and its list of tabs it leaves active does not mention uploads.
  5. Keep the computer awake. A laptop that sleeps stops the transfer; plug it in and change the sleep setting while the upload runs.
  6. If nothing has moved after all of this, reload the page and add the file again. Google does not document resuming a stalled upload on Drive's website after a reload, so expect it to start over.

Is it a browser limit on files at once?

Probably partly, but Google does not say. Google does not document how many files Drive's website uploads at once, so any exact number quoted for it is a guess. What is certain is that a queue exists: the Waiting label is that queue, and a very large batch spends a long time in it. Splitting a big batch into smaller ones, or uploading the biggest files on their own, may shorten the line.

Uploft sets its own limit and shows it: its uploader sends 1 to 6 files at a time (4 by default), set with At a time on the uploader page. The files over that number show Waiting until a place frees up. Lowering the number sends the extra uploads back to Waiting without losing what they have already sent.

How the uploader shows each file's state

In the extension's uploader, every file has one status line, so a queue can be told from a stall at a glance. These are the words it uses:

It saysIt means
WaitingQueued: the file will start when a place frees up under the "At a time" limit. After an interruption it adds how much is already in Drive
Starting or ReconnectingThe upload is being set up, or picking up a file that already has part in Drive
Waiting for the networkThe computer is offline; the file carries on when the connection returns, and the wait does not use up retries
Retrying in N sA connection problem; it tries again, with longer pauses, and marks the file failed after 20 failures in a row with no progress
PausedPaused by you, with Pause all or the file's own button; Resume restarts it
Interrupted at … Choose the file again to continueThe uploader was restarted and needs the file picked again; Drive still holds the part already sent

What the extension fixes and what it can't

Uploft is a free Chrome extension (Chrome 116 or later, on a computer) that targets the causes above.

  • A visible queue. Its uploader shows which files are going and which are waiting, and its limit of 1 to 6 at a time is yours to set.
  • Auto-retry. On drive.google.com it clicks Drive's own Retry button after 5, 20 and 60 seconds, and waits for the network if the computer is offline.
  • Keep-awake and no tab discarding. It asks Chrome to keep the computer awake from inactivity while uploads run, and marks the uploading tab so Chrome does not discard it automatically.
  • A stalled-piece restart in its own uploader: a piece that moves no bytes for 60 seconds is restarted, and the upload continues from what Drive already has.

It cannot fix a full Google storage, and it cannot change how Drive's own website queues files. Keep-awake does not stop a closed laptop lid or Sleep from sleeping the computer. For uploading from a folder on the computer rather than a browser tab, Google makes Google Drive for desktop for Windows and macOS. Uploft is not on the Chrome Web Store yet.

Uploft is free, and its source code is public. It isn't on the Chrome Web Store yet; the home page shows what it does and what it asks for.
