Why is my Google Drive upload so slow?

Published 29 October 2026 · Updated 29 October 2026 · By Sai Nath

Most slow Google Drive uploads are limited by your internet upload speed, not by Drive. Divide the Mbps figure from a speed test by 8 to get megabytes per second, then divide the file size by that. If the time matches, nothing is wrong. If it is far slower, look at Wi-Fi, a VPN and busy tabs.

This guide comes from the maker of Uploft, the Chrome extension mentioned below. Google's behaviour links to Google's own pages and was checked on 29 October 2026; what the extension does comes from its source code.

Check it in three steps

  1. Measure your upload speed. Run a speed test and read the upload figure, not the download one. Say it shows 20 Mbps.
  2. Divide by 8. Speed tests count megabits; files are counted in megabytes, and a byte is 8 bits. 20 Mbps ÷ 8 = 2.5 MB per second.
  3. Divide the file size by that. A 10 GB file is 10,000 MB (decimal units): 10,000 MB ÷ 2.5 MB/s = 4,000 seconds, about 1 hour 7 minutes. At 5 Mbps the same file is 10,000 ÷ 0.625 = 16,000 seconds, about 4 hours 27 minutes.

If your real time is close to the sum, the connection is the limit and only a faster upload speed changes it. If the upload is several times slower than the sum, work through the causes below.

Why is upload slower than download?

Because most home connections sell the two speeds separately, and upload is often the smaller number. The download figure on the plan or in a speed test says nothing about how fast a file can leave your computer. Always use the upload line in the sum above. Your provider's plan page states both figures.

Is one big file slower than many files?

One large file is not slower per byte, but it uses a single stream. Google's guidance for the Drive API is that when a file is sent in chunks they should be multiples of 256 KB and as large as possible so the upload is efficient (see Google's upload guide). Many small files add a per-file cost instead: a resumable upload costs one extra request per file, so a folder of thousands of small files can take longer than the total size suggests.

If one stream does not fill your connection, sending several files at once can use the spare capacity. If one stream already fills it, more files at once add nothing.

Do Wi-Fi, a VPN and other tabs slow it down?

They can, because they all share the same upload bandwidth. Test each in turn:

  • Wi-Fi. Move closer to the router or plug in a cable, then run the speed test again.
  • VPN. Switch it off for the test. A VPN sends your upload through another server first.
  • Other tabs and apps. Video calls, cloud backups, other uploads and streaming all use upload bandwidth. Pause them while a big file goes up.

Is Drive for desktop faster?

Not necessarily. It uses the same internet connection, so a link that limits the browser limits Drive for desktop too. Google says edits sync automatically and you can pause or resume syncing at any time, on its Drive for desktop help page. Google's page gives no speed comparison with the website.

Is an upload that takes hours normal?

Yes, when the sum says so. At 20 Mbps, 50 GB is 50 × 1,000 MB ÷ 2.5 MB/s = 20,000 seconds, about 5 hours 33 minutes. Taking hours is a problem only when the real time is much longer than the sum, or the upload keeps stopping. In that case see why uploads fail or get stuck.

How does Uploft help?

Uploft is a free Chrome extension (Chrome 116 or later) with its own uploader page. It cannot raise your connection's upload speed. What it does is use the connection well and keep a long upload going.

  • Several files at once. Under At a time you choose 1 to 6 files; the default is 3.
  • Piece size that adapts. Each file is sent in pieces that start at 8 MB. If a piece finishes in under 4 seconds the next one doubles, up to 64 MB; if a piece takes over 20 seconds the next one halves, down to 1 MB.
  • Stalls are restarted. A piece that moves no bytes for 60 seconds is sent again, and time offline does not count as failed tries.
  • Progress you can read. The uploader shows the speed and time left, so you can compare it with your sum.

What can't it fix?

  • A slow upload speed. One file goes up at about the speed of Drive's own site, because the pieces of a single file are sent in order and your connection is the limit.
  • Wi-Fi, VPN or other traffic taking the bandwidth.
  • It runs in Chrome on a computer, not on phones, and it isn't on the Chrome Web Store yet.

Uploft is free, and its source code is public. It isn't on the Chrome Web Store yet; the home page shows what it does and what it asks for.
